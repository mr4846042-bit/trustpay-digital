Paycard Solution BD website
=============================

Files:
- index.html: complete responsive website (HTML, CSS and JavaScript in one file)

How to preview:
1. Open index.html in a browser.
2. Test the order form. It opens WhatsApp with the entered order details; the customer must press Send.

Important:
- This is a static website. It does not store orders in a database or create an admin panel.
- The form currently sends order details to WhatsApp number 01978365292 (+8801978365292).
- Confirm that this is your business WhatsApp number before publishing.
- Avoid collecting sensitive card details, passwords, OTPs, or full payment credentials.
- To host for free, upload index.html to a static host such as GitHub Pages or Netlify.
